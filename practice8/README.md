# Практика 8. Материалы к защите

- `Инструкция_заказчику.docx` / `.pdf` — инструкция для заказчика простым языком.
- `Журнал_работ_и_испытаний.md` — журнал работ и протокол испытаний.
- `tests.md` — сводная таблица функциональных тестов.
- `screens/` — снимки работающего стенда.

Презентация в комплект не входит (по требованию заказчика работ).
