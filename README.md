# SMART-HOME — система мониторинга умного помещения

Учебный проект по ПМ03 «Участие в разработке приложений взаимодействия с интеллектуальными
интегрированными системами». Стенд развёрнут в GNS3 (проект **1234567**) и включает пять
виртуальных машин: приёмник показаний, узел IoT с Node-RED, сервер базы данных и сервер
мониторинга, а также рабочую станцию оператора.

## Состав стенда

| ВМ | IP-адрес | Роль | Основные сервисы |
|----|----------|------|------------------|
| WIN-01 | 192.168.10.2 | рабочая станция оператора (Windows Server 2019) | браузер |
| CTRL-01 | 192.168.20.20 | приёмник показаний и команд | `receiver.js`, Docker, порт **8080** |
| IOT-01 | 192.168.30.2 | узел IoT | Node-RED, Docker, порт **1880** |
| DB-01 | 192.168.20.10 | хранение истории | сервис хранения, SQLite, порт **8081** |
| MON-01 | 192.168.20.3 | мониторинг | Prometheus **9090**, Grafana **3000** |
| RTR-01 | 192.168.10.1 / 20.1 / 30.1 | маршрутизатор стенда | NAT, межVLAN-маршрутизация |

WAN-адрес RTR-01 выдаётся по DHCP в сети GNS3 (на момент сдачи — 10.31.6.183).

## Схема обмена данными

```
Node-RED (IOT-01, :1880)
   ├─ POST /api/readings  ───────────────►  CTRL-01:8080  (журнал показаний)
   ├─ POST /api/actuators ───────────────►  CTRL-01:8080  (команды FAN-01)
   ├─ POST /api/readings  ───────────────►  DB-01:8081    (SQLite, история)
   └─ POST /api/actuators ───────────────►  DB-01:8081    (SQLite, события)

Prometheus (MON-01:9090) ── GET /metrics ──► CTRL-01:8080
Grafana   (MON-01:3000)  ── datasource ───► Prometheus
                         └─ правила оповещения ──► Email
```

Датчики **TEMP-01** (zone `server_room`, unit `C`) и **HUM-01** (zone `work_area`, unit `%`)
отправляют показания каждые 5 секунд. Вентилятор **FAN-01**: при температуре больше 30 °C
формируется команда `ON`, иначе `OFF` (режим `auto`).

## Порядок запуска стенда

1. В GNS3 открыть проект **1234567** и убедиться, что все ВМ запущены.
2. RTR-01: проверить маршрутизацию и NAT — `systemctl status lab-router` (служба
   включает `ip_forward` и masquerade на внешний интерфейс).
3. CTRL-01:
   ```
   cd /root/practice4/ctrl && docker compose -f compose.yml up -d
   curl -s http://127.0.0.1:8080/health
   ```
4. IOT-01:
   ```
   cd /root/practice4/iot && docker compose -f compose.yml up -d
   ```
   Поток Node-RED хранится в контейнере и разворачивается командой
   `POST http://127.0.0.1:1880/flows` (файл `practice7/flow-fan-mon.json`).
5. DB-01:
   ```
   cd /root/practice6 && docker compose -f compose.yml up -d
   curl -s http://127.0.0.1:8081/health
   ```
6. MON-01:
   ```
   systemctl start prometheus grafana-server
   ```
7. Проверки: `curl /health` на CTRL и DB, цель `office-controller` в Prometheus — UP,
   панель Grafana показывает значения, в веб-интерфейсе DB появляются новые строки.

## Обслуживание и известные особенности

- Служба `lab-router.service` на RTR-01 включает `net.ipv4.ip_forward=1` и masquerade
  на `enp2s0`; без неё у ВМ пропадает интернет и связь между VLAN.
- В проекте GNS3 отключено автозакрытие (`auto_close=false`), иначе ВМ выключаются
  при закрытии вкладки web-UI.
- Прямая ссылка на проект в GNS3 web-UI без авторизации открывается пустым экраном
  (особенность версии 3.0.6). Вход: http://10.31.6.68:3080/static/web-ui/bundled,
  логин администратора GNS3, затем проект **1234567**.
- Пароли, SMTP-секреты и рабочая база SQLite в репозиторий не включены.
